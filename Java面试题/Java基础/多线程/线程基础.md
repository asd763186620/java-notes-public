# 进程和线程的区别
## 进程：
进程指的是一个程序从磁盘加载到内存，此时就开启了一个进程

## 线程：
线程的指的是执行程序的最小单元，将需要执行的指令发送给cpu。

## 区别：
一个进程可以包含多个线程

多个进程运行时，每个进程有自己独立的内存空间

线程在程序运行时，可以共享同一片内存空间

# 并行和并发的区别
## 并行
同一时间同时运行多件事情能力

多个线程同时运行

### 单核cpu下，无法并行，只是cpu任务调度太快人类无法感知。底层仍是多个线程切换进行运行
### 多核cpu下，每个cpu对应执行一个线程内的指令，此时可以是并行状态
## 并发
同一时间应对多件事情

由单个cpu进行调度，多个线程轮换执行

# Runnable和Callable接口区别
## Runnable中的run方法无返回值，Callable接口call方法有泛型返回值，可以通过和Future和FutureTask配合异步获取
## Callable接口中的call方法允许抛出异常，而Runnable接口的run方法只能内部处理不能向上抛出
# run方法和start方法区别
执行run方法相当一个普通方法并没有开启线程，可以执行多次

执行start方法用来启动一个线程只能启动一次

# wait和sleep方法的区别
## 相同点
### 都能让当前线程进入阻塞状态，都可以被打断唤醒
## 不同
### 方法归属不同，wait是Object类的成员方法每个对象都有，sleep是Thread类的静态方法
### 带时间参数的两个方法都能在到时间后醒来
### wait可以被notify唤醒，如果不唤醒则会一直等待
## 锁特性不同
### wait只能在对象获取到锁时使用
### sleep可以直接被Thread调用
### wait执行时释放锁不必等到方法参数的时间到，其他线程可以去获得锁
### sleep如果在被锁包围的代码块中执行，不到sleep定义的时间结束不会释放锁
# 如何停止一个正在运行的线程
## 使用线程标志，使线程正常退出，线程内部定义一个布尔型的成员变量，在外部调用线程时通过控制布尔类型的状态位改变停止线程
## 使用线程.stop方法（不推荐）
## 使用interrupt方法中断线程
### 打断阻塞的线程，（sleep、wait、join）的线程，线程会抛出interruptedException
### 打断正常的线程，可以根据打断状态俩标记是否退出线程
