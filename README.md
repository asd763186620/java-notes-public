# 面试笔记

这个仓库整理 Java 后端面试复习笔记，内容覆盖 Java 基础、集合、多线程和 JVM。笔记以问题和知识点为主，结合代码片段、运行机制、常见坑点和面试回答思路，适合按专题快速复习。

## 内容范围

- Java 基础：语法细节、包装类、集合遍历、哈希冲突等常见基础问题。
- 集合：HashMap、ConcurrentHashMap、List 的底层结构、扩容、线程安全和使用注意事项。
- 多线程：线程基础、并发安全、线程池参数、阻塞队列、拒绝策略和典型使用场景。
- JVM：运行时结构、类加载、垃圾回收、JVM 调优与实践问题。
